# Finanças Fácil — base legal

Política de privacidade e termos de uso do app **Finanças Fácil**, publicados
pelo GitHub Pages em **https://cortexistech.github.io/financasfacil-BaseLegal/**.

Esses links são os que constam nas fichas da Google Play e da App Store, então
os endereços dos arquivos não devem mudar.

| Arquivo | Endereço |
|---|---|
| `index.html` | https://cortexistech.github.io/financasfacil-BaseLegal/ |
| `politica-de-privacidade.html` | https://cortexistech.github.io/financasfacil-BaseLegal/politica-de-privacidade.html |
| `termos-de-uso.html` | https://cortexistech.github.io/financasfacil-BaseLegal/termos-de-uso.html |

## Atualização

A fonte dos textos é a pasta `docs/legal/` do repositório
[ControleFinanceiroAndroid](https://github.com/cortexistech/ControleFinanceiroAndroid).
Ao alterar um texto lá, copie os arquivos para cá; a publicação acontece
sozinha a cada push na `main`.
